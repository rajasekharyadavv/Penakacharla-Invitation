# 💍 Rajeswari & Arvind Wedding Invitation

A mobile-friendly wedding invitation website for GitHub Pages.

## Files

- `index.html` — invitation page
- `style.css` — latest design and responsive styling
- `script.js` — flower animation and Google Maps button

## Features

- Tap **Open Invitation**
- Flower/petal animation
- Wedding invitation card
- Reception and wedding details
- **Open Location** button
- Mobile-friendly design
- No personal photos required

## GitHub Pages

Upload all three files to the root of your GitHub repository and enable:

Settings → Pages → Deploy from a branch → `main` → `/ (root)`

Then open your GitHub Pages URL.
